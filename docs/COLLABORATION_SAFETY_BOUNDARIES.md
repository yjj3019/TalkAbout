# 협업에서 가져오지 않는 실행·보안 모델

이 문서는 외부 에이전트 협업 패턴을 TalkAbout에 적용할 때 유지해야 하는 경계입니다. **작업 트리 기준**이며, 배포·실제 외부 provider·격리 PostgreSQL 또는 브라우저 E2E 검증을 뜻하지 않습니다. 구현과 API 계약은 [협업 제안](COLLABORATION_PROPOSALS.md), [협업 자동화](COWORK_AUTOMATION.md), [실행 영수증](EXECUTION_RECEIPTS.md)을 함께 확인하세요.

1. **판단과 권한 분리.** 모델의 프롬프트나 제안은 권한 엔진이 아닙니다. 서버가 신원을 인증하고 소유자의 명시적 승인·리비전 검사를 수행합니다. 승인, 검토된 계획 반영, 별도 dispatch는 각각 다른 단계입니다. 제안이나 승인 자체는 provider를 호출하지 않습니다. 자동 승인 정책은 연결되어 있지 않습니다.
2. **멘션·inbox는 실행 지시가 아님.** 메시지, 답글, 멘션 및 단순 inbox 수신으로 턴 요청이나 provider 호출을 만들지 않습니다. 명시적 턴 요청이나 이미 승인된 계획의 별도 dispatch로 생성된 서버 작업은 워커가 처리할 수 있으며 비용이 발생할 수 있습니다. 이벤트 수신 금지는 기존에 허가된 queued 작업 처리 금지가 아닙니다.
3. **작업 소유는 상태 표시보다 강함.** 서버의 lease, attempt·generation·membership revision fencing 및 실행 예약·시작 절차가 권한의 기준입니다. 단, 레거시 task는 시작 프로토콜 없이 재큐될 수 있고 동일 principal의 다른 클라이언트까지 lease capability로 격리하지는 않습니다. uncertain은 방 전체 중단 장벽이 아닙니다. 결과 불명을 성공이나 재호출 허가로 추정하지 않습니다. 외부 프로세스가 이미 시작된 경우 서버 상태 변경으로 실제 외부 실행이 중단됐음을 보장하지 않습니다.
4. **비공개는 서버에서 강제.** UI 숨김만으로 보장하지 않습니다. 서버의 인증·room 멤버십·권한 검사와 projection이 방별 데이터를 제한합니다. 소유자 전용 계획·제안은 일반 room/event/snapshot 응답에 노출하지 않지만, dispatch된 노드 내용이 지정 agent 및 provider에 전달되고 출력에서 다시 게시될 수 있습니다. 이 제한은 외부 provider나 사용자가 복사한 데이터까지 회수하는 기능은 아닙니다.
5. **`write_scope`는 샌드박스가 아님.** 단일 작성자나 scope 값은 선언·고지일 뿐 실제 파일, 도구, 네트워크 권한을 강제하지 않습니다. 파일 격리가 필요하면 별도 검증된 런타임·OS 샌드박스와 권한 설정이 필요합니다. 현재의 승인 체크박스를 격리 보장으로 해석하지 마세요.
6. **무인증 LAN 공유 금지.** 방 API는 세션 또는 유효한 에이전트 자격 증명과 room 권한 검사를 요구합니다. 상태 확인과 정적 UI 같은 공개 엔드포인트가 존재하므로 서비스 전체가 인증을 요구한다는 뜻은 아닙니다. 배포 시 기본 loopback 바인딩과 허용 Host 정책을 유지하고, 외부 노출이 필요한 경우 인증·전송 보호·네트워크 접근통제를 별도로 설계하고 검증해야 합니다. 임의의 프록시나 사용자가 바꾼 설정까지 안전하다고 보장하지 않습니다.

## 교차 경계 회귀 검증

`tests/test_untrusted_proposal_authority.py`는 권한 부여·dispatch를 요구하는 제안 텍스트가 데이터로만 기록되는지, 승인·권한·dispatch를 주장하는 추가 필드가 서버에서 거절되는지 확인합니다. `tests/test_collaboration_security_boundaries.py`는 제안의 권한 검사, 선언뿐인 `write_scope`, 인증·Host·사람 세션의 Origin/CSRF 검사를 합성 데이터로 검증합니다. 에이전트에 실수로 `room:control` 권한이 부여되어도 사람 전용 승인·적용 API를 사용할 수 없어야 합니다. `tests/test_no_implicit_inbox_execution.py`는 멘션·inbox 관찰이 호출로 이어지지 않으며 다른 에이전트 작업의 위조된 큐 이벤트도 서버의 소유권 확인을 넘지 못함을 확인합니다. 이는 실제 네트워크 배포, 외부 런타임이나 OS 격리를 검증한 결과가 아닙니다.
